🪄 Tarik Bookmarklet Ini ke Bookmark Bar

1. Kenapa Cookie Dibutuhkan?

YouTube sering membatasi video tertentu (konten edukasi 18+, verifikasi bot cloud). Cookie sesi membantu runner membaca video stream seperti layaknya browser normal Anda.

2. Apakah Password Saya Aman?

100% SANGAT AMAN. Cookie hanya berisi token sesi web, TIDAK PERNAH berisi password atau email Anda. Sistem tidak memiliki akses ke akun Google Anda.

3. Enkripsi Brankas Privat

Setiap cookie dan API key yang Anda simpan langsung dienkripsi menggunakan Fernet AES-128 dan disimpan di dataset privat khusus Anda.
